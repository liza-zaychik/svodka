# svodka

**Ежедневная сводка почты для тех, кто ненавидит читать почту.**

Раз в день svodka читает твой Gmail, разбирает его по правилам, написанным
обычными словами, и показывает одну карточку: что требует действия, что стоит
прочитать и в чём она не уверена. Мусор получает ярлык. Ничего не удаляется.
Решения — одним нажатием, в том числе с телефона.

[English version](README.md)

## Зачем ещё один почтовый ассистент

Почти все AI-почтовики просят доверия авансом: *ИИ разберёт почту за тебя*.
svodka устроена наоборот — **всё, что она делает, можно проверить**.

- **Твои правила, обычными словами.** Чек из продуктового — мусор через неделю,
  чек на технику хранится год ради гарантии, код подтверждения — мусор сразу.
  Это пишется в `rules.md`, а не фильтрами.
- **Ничего не удаляется.** Мусор получает ярлык `🗑 На удаление`, чистишь его ты.
- **Сомнения показываются, а не прячутся.** До трёх переписок, в которых разбор
  не уверен, попадают в «Проверить» — каждая с причиной.
- **Решения запоминаются.** «Оставить» убирает переписку из будущих сводок —
  пока в ней кто-нибудь не ответит.

## Как это работает

```
GitHub Actions, каждое утро (бесплатно)
  → читает Gmail напрямую, по твоему собственному OAuth-ключу
  → Claude раскладывает переписки по rules.md и пишет пересказ в одну строку
    для тех, что ты действительно прочитаешь
  → код помечает мусор и сохраняет сводку черновиком в Gmail
  → во входящие ложится короткое письмо, и пуш присылает сам Gmail

Карточка — артефакт Claude, публикуется один раз, ссылка постоянная
  → при открытии читает свежий черновик
  → кнопки работают с Gmail через твой Gmail-коннектор в Claude
```

Компьютер держать включённым не нужно, сервера нет.

## Что понадобится

- Аккаунт Gmail.
- Подписка Claude Pro или Max. Разбор идёт за её счёт через `claude setup-token`,
  отдельных счетов за API нет.
- Аккаунт GitHub. Хватает приватного репозитория и бесплатных минут Actions:
  прогон занимает около 8 минут, это примерно 250 минут в месяц при 2000 бесплатных.
- Gmail-коннектор, подключённый в Claude (Настройки → Коннекторы) — через него
  работают кнопки карточки.

## Установка

1. **Use this template → Create a new repository.** Репозиторий делай
   **приватным** — почему, см. [Приватность](#приватность-и-безопасность).
2. Склонируй его и открой папку в Claude Code.
3. Запусти `/setup`. Claude задаст несколько вопросов про твои правила, проведёт
   через ключ в Google Cloud (около 15 минут, один раз), сохранит секреты,
   опубликует карточку и запустит пробный прогон.

Хочешь руками? `/setup` — это читаемый чек-лист:
[.claude/commands/setup.md](.claude/commands/setup.md).

## Настройка

- `rules.md` — сроки хранения, список «не трогать», порядок важности.
  Обычными словами; Claude читает его на каждом прогоне. Основа — `rules.example.md`.
- `config.json` — язык сводки, часовой пояс, лимиты разделов, названия ярлыков
  и переключатели пуша: `notify.ready` (сводка готова), `notify.failed` (прогон упал),
  `notify.email` (пуш письмом во входящие). Поставь `false`, чтобы отключить.
  Пример — `config.example.json`.
- Переменная репозитория `DRY_RUN=true` — сводка целиком, но ярлыки не ставятся.
- `.github/workflows/daily.yml` — расписание.

## Приватность и безопасность

- **Что видит Claude:** отправителя, тему и первые 200 символов последнего письма
  каждой переписки. Тела писем и вложения не читаются, ссылки не открываются.
- **Где хранится сводка:** черновиком в твоём же ящике. Больше нигде.
- **Логи:** в логи пишутся только счётчики. Репозиторий всё равно держи
  приватным — логи Actions публичных репозиториев видны всем.
- **Команды внутри писем:** у шага разбора нет доступа к Gmail вообще — только
  чтение и запись двух локальных файлов. Ярлыки и черновик ставит потом обычный
  код, в жёстких лимитах. Письмо, которое пытается командовать, попадает в «Проверить».
- **Удаление:** в коде прогона нет ни одной команды удаления. В корзину письмо
  попадает только по кнопке в карточке, и Gmail хранит корзину 30 дней.
- **Экран «приложение не проверено»:** OAuth-клиент твой собственный и только
  для тебя, поэтому Google один раз предупреждает. Так и должно быть.

## Ограничения

- Только Gmail, один ящик на репозиторий.
- GitHub может запускать задачи по расписанию с опозданием на часы, поэтому
  расписание стоит рано.
- Карточке нужен claude.ai: кнопки работают через твой Gmail-коннектор в Claude.
